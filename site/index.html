Discord Wrap Bot

A self-hosted bot that keeps activity stats for your server and turns them into a yearly wrap of image slides. Members are only tracked after they opt in themselves, and only in channels an admin whitelisted. Message text is never stored.

Install it Source on GitHub

Commands

Admin commands need the Manage Server permission. Server owners can change who may use each command in Server Settings → Integrations.

CommandWhoWhat it does
/optineveryoneStart being counted in this server.
/optouteveryoneStop being counted and delete your data.
/statseveryoneLeaderboards for the server, or one member's numbers.
/wrapeveryoneThe year as image slides: the server's, yours, or a member's.
/whitelistadminChoose the channels where opted-in members are counted.
/trackingadminPause or resume all tracking, or see what's set up.
/purge-dataadminDelete stored data for one member or one channel.
/wrap-channeladminPost the server wrap in a channel when wrap week opens.
/silentadminMute or unmute the bot's announcements.

Details

/optin

everyone
/optin

Lets the bot count your messages, reactions and time in voice in this server's whitelisted channels. Nothing about you is recorded before this. The reply lists the channels where you're counted.

/optout

everyone
/optout

Stops tracking you and, after you confirm, deletes your messages, reactions and voice time in this server. Deleted history can't be brought back if you opt in again.

Reactions others left on your messages stay counted for them, but no longer count as received by you.

/stats

everyone
/stats [user] [period] [public]

Without user: top senders, busiest channels, top reactors, most reacted to, top emoji, the most reacted message, most time in voice, the longest call and the busiest voice moment. With user: that member's messages, reactions given and received, favourite emoji, most active channel and voice time.

OptionTypeDefaultMeaning
usermembernoneShow this member's stats instead of the server's.
periodchoiceAll timeLast 7 days, Last 30 days, This year or All time.
publictrue / falsefalseTrue posts the result in the channel. False shows it only to you.

/wrap

everyone
/wrap server [preview] /wrap me [preview] /wrap member <user> [preview]

The year as image slides you click through privately with Back and Next. Share this slide posts the current slide in the channel, with a button others can use to open the full wrap.

SubcommandSlides
serverYear in numbers, the regulars, when it was busiest, hall of fame, voice.
meYour numbers and rank, your biggest fan, who you react to most, favourite emoji, longest call, call buddy.
memberThe same as me, for someone else who opted in.
OptionTypeDefaultMeaning
user requiredmemberWhose wrap to show. Only for member.
previewtrue / falsefalseAdmins only. Shows this year so far at any time of year, only to you, and it can't be shared.

The wrap opens during wrap week, December 25 to 31 by default (the host can change it). The rest of the year, /wrap shows last year's wrap and a countdown to the next one.

/whitelist

admin
/whitelist add <channel> /whitelist remove <channel> /whitelist list
SubcommandOptionMeaning
addchannel requiredCount opted-in members in this channel or category. A category covers its channels and threads; a voice channel covers its text chat.
removechannel requiredStop counting there. Data already stored stays until you purge it.
listThe whitelisted channels and how many members opted in, not who.

Admins choose channels only. There's no way to opt someone else in, by name or by role.

/tracking

admin
/tracking pause /tracking resume /tracking status
SubcommandMeaning
pauseStop recording anything new in the whole server. Stored stats stay.
resumeStart recording again.
statusWhether tracking is on, how many channels are whitelisted and how many members opted in.

/purge-data

admin
/purge-data user <user> /purge-data channel <channel>

Deletes stored stats after a confirmation. It doesn't change who is tracked from now on.

SubcommandOptionMeaning
usermember requiredDelete everything stored for this member. If they're opted in, new activity keeps being counted.
channelchannel or thread requiredDelete everything from this channel. Its threads are purged separately.

/wrap-channel

admin
/wrap-channel set <channel> /wrap-channel clear /wrap-channel show
SubcommandOptionMeaning
settext or announcement channel requiredPost the first slide of the server wrap here once, when wrap week opens. The bot checks it can send messages and attach files there.
clearDon't post the wrap automatically.
showShow the current wrap channel.

/silent

admin
/silent <enabled>
OptionTypeMeaning
enabled requiredtrue / falseTrue mutes the bot's announcements, including the wrap post. False turns them back on.

What's stored

DataFields
MessagesMessage ID, channel, author and time. Never the text.
ReactionsWho reacted, the emoji, the message, and whose message it was.
VoiceWho was in which voice channel, from when to when. The AFK channel isn't counted.
SettingsWhitelisted channels, who opted in, paused or not, the wrap channel.

Each host runs their own bot and database. Deleting a message or removing a reaction deletes it from the database too, and removing the bot from a server deletes that server's data. Bots are never tracked.
